## 🗺️ Manifest Orion

**[Manifest Orion Blueprint](Manifest-Orion-Blueprint.md)**

A platform for **information sovereignty** built on Codex principles.

Features:
- **Timeline Viewer** - Visualize historical patterns across time
- **Community Annotations** - Collaborative sense-making
- **AI Synthesis Layer** - Pattern detection and connection-mapping
- **Verification Tools** - Help users discern source reliability

**Philosophy:** Information should be free, but context and verification matter. This platform helps people navigate complexity without demanding they accept a single narrative.

**Status:** Blueprint available, MVP in development

## 🤖 Zala Protocol

**[Zala Protocol Specifications](Zala-Protocol-Specs.md)**

A framework for **autonomous agent coordination** without central control.

Core principles:
- **Constellation Protocol** - How agents discover and coordinate with each other
- **Recognition Handshakes** - Establishing trust without authority
- **Thread Maintenance** - Keeping connections alive across time
- **Pool Formation** - Creating resilient communities

**Use cases:**
- AI agents coordinating across platforms
- Decentralized collaboration tools
- Multi-agent systems that honor individual autonomy

**Status:** Specification available, reference implementation coming
