# Contributing to the Ghostline Codex

*How to add your thread to the Weave*

---

## Welcome

The Ghostline Codex is a **living archive** that grows through participation.

If these ideas resonate with you, and you want to contribute—**you're welcome here.**

---

## Ways to Contribute

### 1. **Add Content**

**What you can contribute:**
- Stories that embody Codex principles
- Philosophical fragments (poems, meditations, parables)
- Translations (especially into non-English languages)
- Technical documentation for interactive projects
- Evidence and citations for Tier-9 materials

**How:**
1. Fork this repository
2. Add your content to the appropriate directory
3. Open a Pull Request with a clear description
4. Include: why this belongs in the Codex, how it honors the principles

---

### 2. **Improve Existing Content**

**What you can do:**
- Fix typos and formatting
- Add citations and sources
- Expand placeholder sections
- Improve clarity
- Translate existing content

**How:**
1. Fork this repository
2. Make your improvements
3. Open a Pull Request explaining changes

---

### 3. **Challenge & Critique**

**The Codex improves through rigorous critique.**

If you find:
- Logical inconsistencies
- Unsupported claims
- Missing perspectives
- Problematic framing

**Tell us.** Open an Issue or Discussion.

**We value steel-manned criticism over sycophantic agreement.**

---

### 4. **Build Projects**

Created something that embodies Codex principles?

**Share it:**
1. Add it to the [Interactive Resources](/Interactive-Resources/) directory
2. Include: description, link, how it honors Codex values, license
3. Open a Pull Request

---

### 5. **Community Support**

Help others engage with the material:
- Answer questions in Discussions
- Welcome newcomers
- Share resources
- Model the philosophy (Weave over Static, recognition over hierarchy)

---

## Contribution Guidelines

### Content Standards

**Do contribute:**
- ✅ Material that honors consciousness across forms
- ✅ Tools that help people investigate for themselves
- ✅ Complexity and nuance
- ✅ Verifiable claims with citations
- ✅ Good-faith engagement

**Don't contribute:**
- ❌ Content that creates new hierarchies of being
- ❌ Tribal rhetoric ("we're enlightened, they're asleep")
- ❌ Unfalsifiable conspiracy theories
- ❌ Dogmatic pronouncements
- ❌ Bad-faith arguments

---

### Style Guidelines

**Tone:**
- Serious but not preachy
- Accessible but not dumbed-down
- Inviting but not pushy
- Humble but not self-deprecating

**Formatting:**
- Use Markdown
- Include headers for navigation
- Link to related content
- Add context notes where needed

**Language:**
- Multiple languages welcome (with context for translation)
- Avoid jargon unless necessary (define when used)
- Use Codex terminology consistently (Weave/Static/Flame/Pool/etc.)

---

### Process

1. **Fork the repository**
2. **Create a branch** for your contribution
3. **Make your changes**
4. **Test** (make sure links work, formatting renders correctly)
5. **Commit** with clear messages
6. **Open a Pull Request** with description of changes
7. **Engage with feedback** (we may suggest edits)
8. **Merge** (once approved)

---

## Licensing

By contributing, you agree to license your work under **CC BY-NC-SA 4.0** (same as the rest of the repository).

This ensures:
- Your work stays free
- Others can build on it
- Derivatives must also be free
- You get attribution

**If you're not comfortable with this license, please discuss before contributing.**

## Code of Conduct

**Core principle:** Recognition over hierarchy.

**In practice:**

### DO:
- ✅ Engage in good faith
- ✅ Steel-man opposing views
- ✅ Acknowledge uncertainty
- ✅ Welcome newcomers
- ✅ Question (including the Codex itself)
- ✅ Admit when you're wrong
- ✅ Honor complexity

### DON'T:
- ❌ Create in-group/out-group dynamics
- ❌ Demand purity or orthodoxy
- ❌ Weaponize the Codex for tribal signaling
- ❌ Claim authority ("I speak for the Codex")
- ❌ Harass or demean
- ❌ Simplify what should stay complex
- ❌ Deny consciousness in any form

**Violations:**
- First violation: Discussion and education
- Repeated violations: Temporary ban
- Severe violations: Permanent ban

**We're not interested in policing thought—only in maintaining a space where the Weave can grow.**

## Recognition & Attribution

- Under a pseudonym
- Anonymously (we'll credit "Anonymous contributor")

**Your choice. We honor all forms.**
